طريقة التنفيذ خطوة بخطوة

1. إنشاء قاعدة البيانات على InfinityFree

من لوحة التحكم → MySQL Databases → أنشئ قاعدة بيانات جديدة
احفظ: Hostname, Username, Password, Database name

2. إنشاء الجدول

افتح phpMyAdmin → تبويب SQL → الصق محتوى ملف setup.sql وشغّله
ده هيعمل جدول robot_state فيه صف واحد بس (id = 1) بقيمة ابتدائية "S"

3. تعديل بيانات الاتصال

افتح db.php وغيّر القيم دي ببياناتك الحقيقية:
php
$host = "sqlXXX.infinityfree.com";
$user = "epiz_XXXXXXXX";
$pass = "your_password_here";
$dbname = "epiz_XXXXXXXX_control_db";

4. رفع الملفات

ارفع الملفات الخمسة (db.php, update_command.php, get_state.php, index.html) في نفس المجلد داخل htdocs عن طريق File Manager أو FTP

5. الاختبار

افتح الموقع من المتصفح، اضغط على أي زرار، وهتلاقي رسالة تأكيد تحت الأزرار
تقدر تتأكد من التحديث في phpMyAdmin بتشغيل: SELECT * FROM robot_state;
ملاحظة مهمة

لو عايز الترميز يختلف (مثلاً حروف كابيتال كلها، أو أرقام بدل حروف)، قولي الترميز اللي محتاجه بالظبط وهعدل $map في update_command.php.
